## 🧩 What is Forge Frontier Core?

**Forge Frontier Core** is the official support mod for the acclaimed modpack [**Create - Forge Frontier**](https://www.curseforge.com/minecraft/modpacks/forge-frontier). It was developed to address core gameplay challenges, eliminate mod conflicts, and introduce a scalable foundation for new content within the Create ecosystem.

This Java-based extension builds upon the innovation of KubeJS scripting, offering robust tools, compatibility fixes, and performance-enhancing features that enhance every player’s Forge Frontier experience.

---

## ⚙️ Key Features

- 🔥 **Gameplay Refinement**: Removes disruptive mechanics like the _Seal Crumbling_ from **Nether Remastered**, ensuring smooth quest progression.
- 🥤 **Enhanced Compatibility**: Prevents unintended lava interactions with **Create: Dreams and Desires** milkshakes, preserving gameplay logic.
- 🚧 **Custom Systems Foundation**: Serves as the backend for transitioning KubeJS-defined items, fluids, and blocks into native Java code.
- 🌋 **Molten Vents Overhaul (Upcoming)**: Sets the stage for a complete rework of **Molten Vents**, focusing on immersion, customization, and performance.
- 🔧 **Energetic Blaze Burner**: Introduces a powerful burner for **Applied Energistics** resource processing in advanced automation setups.
- 🛩️ **Jetpack Integration**: Enables **Create Stuff & Additions Jetpacks** to use **Curios slots**, allowing flight without sacrificing armor slots.

Together, these features support a modular, high-performance environment for players to explore, automate, and innovate.

---

## 🚀 What’s Coming Next?

The development roadmap for Forge Frontier Core includes:

- 🧪 Full migration of KubeJS scripts into native code for long-term support and enhanced pack stability
- 🪨 New **stone variant** and **fluid mechanics** to enrich resource processing chains
- 🧱 Mod-exclusive **structures, items, and integration points** designed for the Landscapes Reimagined ecosystem

These features are focused on enhancing modded Minecraft’s depth, creativity, and user experience.
